UZSE Backtest App is an open-source toolkit that bridges the gap between the Uzbekistan Stock Exchange (UZSE) and the Pine Script ecosystem. It scrapes raw trade data directly from uzse.uz, stores it in MongoDB, aggregates it into continuous OHLCV candlestick series, and feeds the result into the backtest-kit editor — giving you full TradingView-style technical analysis on a market that TradingView doesn't support.

## How It Works

UZSE Backtest App follows a three-stage pipeline:

<Steps>
  <Step title="Download Trade Data">
    Use `download-trades.ts` to scrape paginated trade results from uzse.uz using a headless Playwright browser. HTML pages are saved locally in `tmp/`.
  </Step>
  <Step title="Import into MongoDB">
    Run `import-trades.ts` to parse the saved HTML tables, deduplicate records via SHA1 hash, and insert trades into the `trade-results` collection.
  </Step>
  <Step title="Build Candlesticks">
    Execute `build-candles.ts` to aggregate trades into OHLCV candles across 11 timeframes (1m → 1d), filling intraday and non-trading day gaps automatically.
  </Step>
  <Step title="Analyze with Pine Script">
    Start the backtest-kit editor with `npm start` and apply Pine Script indicators to your UZSE candle data.
  </Step>
</Steps>

## Key Features

<CardGroup cols={2}>
  <Card title="Playwright Scraping" icon="browser">
    Headless browser automation handles pagination and JavaScript-rendered pages on uzse.uz with automatic retries.
  </Card>
  <Card title="Idempotent Imports" icon="shield-check">
    SHA1-based deduplication ensures re-running any script never creates duplicate records in MongoDB.
  </Card>
  <Card title="11 Timeframes" icon="clock">
    From 1-minute to daily candles — all built from the same raw 1m series for perfect consistency.
  </Card>
  <Card title="Continuous Series" icon="wave-sine">
    Intraday gaps and non-trading days are automatically filled so indicators always receive a gapless series.
  </Card>
  <Card title="Batch Fetch Scripts" icon="terminal">
    Cross-platform scripts (`fetch.sh` / `fetch.bat`) download and import the full UZSE history from Feb 2018 to present.
  </Card>
  <Card title="Reference Schemas" icon="database">
    Typed Mongoose models for `trade-results` and `candle-items` with unique indexes for safety.
  </Card>
</CardGroup>

<Note>
  No TradingView account or API key is required. All data is collected directly from the public UZSE trade results page at uzse.uz.
</Note>
